# Face Recognition GUI Tool

This project is a simple yet effective desktop application that uses Computer Vision to identify people from uploaded images. It is built to demonstrate the integration of GUI (Tkinter) with AI/ML libraries (OpenCV & Face_recognition).

## Features
- **File Upload:** Graphical interface to select images from your local storage.
- **Face Detection:** Real-time processing to detect and identify faces.
- **Database Comparison:** Compares uploaded images against a pre-defined directory of known faces.

## Tech Stack
- **Python**
- **OpenCV** (Image processing)
- **Face_recognition** (AI model)
- **Tkinter** (GUI interface)
